# Folder Custom Icons

Mod pour [Zen Browser](https://zen-browser.app) (via [Sine](https://github.com/sineorg/sine)).

- Affiche **uniquement l'icône** des dossiers, sans la forme du dossier, centrée.
- Ajoute une galerie **« Mes images »** dans le sélecteur d'icônes des dossiers : colle un lien direct vers une image, elle est enregistrée et réutilisable en un clic.

## Utilisation
1. Clic droit sur un dossier → « Changer l'icône ».
2. En bas du panneau : **Ajouter une image par URL…** (lien direct `https://…/image.png`, pas le code HTML d'intégration).
3. Clic sur une miniature pour l'appliquer ; clic droit sur une miniature pour la supprimer.

Les images sont stockées dans `zen-custom-icons.json` (dossier du profil). Préférer des images < 100 Ko.

## Réglages
Taille et opacité : `CFG` en haut de `JS/zen-folder-icons.uc.js`.

## Installation
Dépôt GitHub → Sine → installer depuis l'URL du dépôt.
